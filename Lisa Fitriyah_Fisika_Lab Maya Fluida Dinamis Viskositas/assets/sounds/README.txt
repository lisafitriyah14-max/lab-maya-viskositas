FOLDER SUARA / SOUNDS
=====================
Lab Maya Viskositas menggunakan Web Audio API untuk semua efek suara.
Suara dibuat secara programatik (synthesized) — tidak memerlukan file audio eksternal.

Jika ingin menambahkan file suara kustom (.mp3/.wav/.ogg), letakkan di folder ini
dan referensikan dari index.html menggunakan:
  new Audio('assets/sounds/nama_file.mp3')
